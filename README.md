# Rabbit Client

Rabbit Client is an Android launcher project for Minecraft Bedrock with an original, modular UI and a separate client-integration layer.

## Project status

This repository is the starting point for the Android app. The current UI is a launcher prototype; module switches are interface/demo state and do **not** modify Minecraft yet. A supported in-game integration layer must be implemented and tested before those modules can be described as functional.

## Planned areas

- Launcher dashboard and instance management
- Import/export and backup workflows
- Worlds, packs, and supported add-on discovery
- Theme and appearance settings
- Independent module registry, settings, and profiles
- HUD editor and supported in-game integration

## Build

Open this project in Android Studio with a compatible Android SDK and JDK 17. A GitHub Actions workflow will build a debug APK and publish it as an artifact.
